# StrawWU Theme Curation

深色主題策展目錄（`post-ux-theme-curation`）。

| 檔案 | 用途 |
|------|------|
| `theme-manifest.yaml` | GTK / icon / shell 主題規格與 gsettings 預設 |
| `../usr/share/themes/StrawWU-Dark/` | GTK3/4 + GNOME Shell 主題資產 |
| `../usr/share/glib-2.0/schemas/99_strawwu-branding.gschema.override` | 映像 branding overlay 預設 |
| `../source/strawwu-colors.md` | Teal `#14B8A6` 品牌色票 |

Debian 套件：`strawwu-gtk-theme`、`strawwu-icon-theme`（由 `build-os-debs.sh` 建置）。
